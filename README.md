# 分譲マンション管理組合 議案書自動作成・整合性チェック

React / TypeScript / Express で構成された、分譲マンション管理組合向けの総会議案書作成支援アプリです。

## 主な機能

- 過去総会議事録の登録・AI解析（5回制限なし）
- 今期議案書ドラフトの自動作成
- 過去決議との整合性チェック
- 通常議案書・監査付き議案書の Word 出力
- 担当者アカウント別ワークスペース保存
- 複数物件管理

## 今回の改修点

各物件担当者が、それぞれのアカウントで作業・保存できるようにしました。

- 担当者アカウントID + 保護キーでログイン
- アカウント単位で保存領域を分離
- 他担当者の保存内容に影響されないワークスペース構造
- 1担当者が複数物件を管理可能
- 保存対象: 物件一覧、選択物件、過去議事録DB、議案ドラフト、整合性チェック結果、作成条件

## 保存API

- POST `/api/workspace/load`
- POST `/api/workspace/save`

保存先は `data/workspaces/` 配下です。担当者アカウントIDと保護キーから生成したSHA-256ハッシュをファイル名にするため、保存領域はアカウントごとに分離されます。

## ローカル実行

```bash
npm install
npm run lint
npm run build
NODE_ENV=production npm run start
```

開発実行:

```bash
npm run dev
```

## 環境変数

Gemini API を使う場合は、`.env.local` またはデプロイ環境で以下を設定してください。

```bash
GEMINI_API_KEY=your_api_key
```

## 本番運用上の注意

`data/workspaces/` は永続化が必要です。デプロイ先のファイルシステムが一時領域の場合は、永続ディスクまたはDBへの移行が必要です。


## 追加改修: 過去議事録の登録上限撤廃

- 過去総会議事録DBは直近5回分に限定しません。
- 登録済み議事録一覧は対象マンションの全件を期の降順で表示します。
- 複数担当者・複数物件の保存分離仕様は維持します。
